# עוזר נהיגה לאייפון: שלב 1

עוזר קולי בעברית לנהיגה. נכתב ב-Windows ו**עדיין לא קומפל או הורץ**, לכן צפויות שגיאות קומפילציה בהרצה הראשונה.

## מה יש בשלב הזה

- שיחה קולית עם Claude, כולל הקראה בזמן שהתשובה נכתבת וחיפוש באינטרנט
- הפעלה במילת הפעלה, ואפשרות להמשיך לדבר בלעדיה מיד אחרי תשובה
- קריאת היומן והוספת אירועים
- חיוג: אישור בקול, ואז לחיצה אחת בחלון של iOS
- וואטסאפ: אישור בקול, ואז נפתחת שיחה עם הטקסט. **ההודעה נשלחת רק בלחיצה על "שלח"**

## מה עוד לא נכלל

Gmail, Google Tasks, Drive, הזמנות, לוח צוות, מילוי טפסים, סוכנים מתמחים, קטיעת העוזר באמצע דיבור ו-CarPlay.

הודעות וואטסאפ נכנסות לא נקראות על ידי האפליקציה, כי iOS לא מאפשר זאת. את זה עושה סירי דרך "הכרזת התראות".

## התקנה בלי Mac: בנייה ב-GitHub והתקנה מ-Windows (חינם)

הבנייה נעשית על Mac בענן של GitHub, וההתקנה נעשית מהמחשב עם Windows בעזרת Sideloadly וחשבון Apple חינמי של בעל המכשיר. **צריך להתקין מחדש כל 7 ימים.**

### א. בנייה ב-GitHub (פעם אחת, ואחר כך אחרי כל שינוי בקוד)

1. נכנסים לחשבון GitHub, רצוי של בעל המכשיר, ויוצרים מאגר (repository) חדש, למשל `drive-agent-ios`.
   - **ציבורי (Public):** זמן הבנייה חינמי ללא הגבלה. אין בקוד מפתחות או פרטים אישיים.
   - **פרטי (Private):** יש כ-200 דקות בנייה בחינם בחודש, שהן בערך 15 בניות.
2. במאגר: **Add file ← Upload files**. גוררים לשם את **כל מה שבתוך** התיקייה `DriveAgentIOS`, כולל התיקייה `.github`, ולוחצים **Commit changes**.
3. עוברים ללשונית **Actions**. הבנייה מתחילה לבד ולוקחת כ-10 דקות.
   - **אדום:** פותחים את הריצה ואת השלב **Show compile errors**, ומעבירים את השגיאות לתיקון. אחרי התיקון מעלים שוב את הקבצים ששונו.
   - **ירוק:** בתחתית דף הריצה, תחת **Artifacts**, מורידים את `DriveAgent-ipa`. זה קובץ ZIP, ובתוכו `DriveAgent.ipa`.

### ב. התקנה על האייפון

1. מתקינים ב-Windows את **iTunes** ואת **iCloud** מהאתר של Apple (לא מ-Microsoft Store), ואת **Sideloadly** מ-sideloadly.io.
2. מחברים את האייפון בכבל ולוחצים בו **"סמוך על מחשב זה"**.
3. ב-Sideloadly: גוררים פנימה את `DriveAgent.ipa`, בוחרים את האייפון ומזינים את ה-Apple ID. **בעל המכשיר מקליד את הסיסמה ואת קוד האימות בעצמו.** אפשר גם להשתמש ב-Apple ID נפרד, שנפתח רק לזה. לוחצים **Start**.
4. באייפון:
   - **הגדרות ← פרטיות ואבטחה ← מצב מפתח** ← מפעילים, והאייפון מבקש הפעלה מחדש.
   - **הגדרות ← כללי ← VPN וניהול מכשירים** ← בוחרים את ה-Apple ID ← **סמוך**.
5. פותחים את "עוזר נהיגה" וממשיכים ל"הגדרות ראשונות באפליקציה" שלמטה.

### ג. חידוש כל שבוע

אחרי 7 ימים האפליקציה מפסיקה להיפתח. מחברים את האייפון ומריצים שוב Sideloadly **עם אותו קובץ ועם אותו Apple ID**. ככה ההגדרות והמפתח שבאפליקציה נשמרים. לא משנים בין התקנה להתקנה את אפשרויות ה-Bundle ID ב-Sideloadly.

חשבון חינמי מאפשר עד 3 אפליקציות כאלה במכשיר בו-זמנית.

**שדרוג בהמשך:** עם חשבון Apple Developer בתשלום (99$ לשנה) עוברים ל-TestFlight, ואז אין חידוש שבועי.

## הקמה ב-Mac (חלופה)

צריך Mac עם Xcode, וחשבון Apple של בעל המכשיר. עם חשבון חינמי צריך להתקין מחדש כל 7 ימים. חשבון Apple Developer בתשלום מבטל את המגבלה הזאת.

1. מעתיקים את התיקייה `DriveAgentIOS` ל-Mac.
2. מתקינים את XcodeGen ומייצרים את הפרויקט מתוך התיקייה:

```bash
brew install xcodegen
```

```bash
xcodegen generate
```

```bash
open DriveAgent.xcodeproj
```

3. ב-Xcode: יעד DriveAgent ← Signing & Capabilities ← בוחרים Team. אם ה-Bundle Identifier תפוס, משנים אותו לשם ייחודי.
4. מחברים את האייפון, מפעילים בו Developer Mode, ולוחצים Run.

## הגדרות ראשונות באפליקציה

במסך ההגדרות:

- **שם המשתמש**
- **שם העוזר**: זו גם מילת ההפעלה. ברירת המחדל היא "שלומי", ואפשר לשנות אותה כאן
- **מפתח API** של Anthropic, של בעל המכשיר. המפתח נשמר ב-Keychain של המכשיר בלבד

בלחיצה הראשונה על "התחל מצב נהיגה" מופיעות בקשות הרשאה למיקרופון, זיהוי דיבור, יומן, אנשי קשר והתראות.

## בדיקות על המכשיר, לפי הסדר

1. **זיהוי עברית**: לומר את מילת ההפעלה ושאלה פשוטה.
2. **מסך נעול**: להפעיל מצב נהיגה, לנעול, ולבדוק שהעוזר ממשיך להקשיב. זה הסיכון הטכני הגדול ביותר.
3. **בלוטות' ברכב**: לבדוק שהקול והמיקרופון עוברים דרך הרכב, גם אחרי ניתוק וחיבור מחדש.
4. **שיחת טלפון באמצע**: לבדוק שההקשבה חוזרת כשהשיחה מסתיימת.
5. **וואטסאפ**: "תגיד ל... ש...", לענות "לא" ולוודא ששום דבר לא נפתח. אחר כך לענות "כן" ולוודא שהטקסט מוכן ולא נשלח לבד.
6. **יומן**: לקבוע אירוע מחר בעשר ולבדוק את התאריך והשעה ביומן.

## פרטיות

- אין בקוד מספר, מפתח או חשבון של אף אדם, ואלה מוזנים במכשיר. הפרט היחיד שמוגדר מראש הוא שם העוזר, "שלומי".
- כשמצב נהיגה פעיל, המיקרופון פתוח כדי לזהות את מילת ההפעלה. אם iOS לא מזהה עברית במכשיר עצמו, האודיו נשלח לזיהוי אצל Apple.
- הבקשות, תוצאות הכלים ותוכן היומן הרלוונטי נשלחים ל-Anthropic. הלוגים כוללים רק קודי סטטוס.
